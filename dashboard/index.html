⚙️ 账户资金
你反复买入卖出同一笔钱时, 用累计投入做分母会偏大。
在这里填入你账户里实际的资金 (含历史加钱), dashboard 会用它重新算盈亏百分比, 反映"账户本身的涨跌"。
保存到浏览器本地, 不上传到服务器
当前算法:
• 持仓盈亏%: 当日浮盈 / 当前持仓成本
• 已实现盈亏%: 累计已实现 / 历史卖出本金
• 总盈亏%: (浮盈 + 已实现) / 账户资金 (你设的数字, 留空 = 累计投入)

总盈亏% 现在 = (floating + realized) / account_funds × 100
